## Generation Guidance

Photoreal, natural skin tones, no readable text on props except the short signs listed, no real brand logos, avoid awkward hands, consistent warm-teal grade, licensed for commercial use.

## Format

WebP preferred (AVIF if available), explicit `width`/`height`, `srcset` for portraits (400, 800, 1200). Under 200 KB each. Total page weight under 1.2 MB before fonts.
